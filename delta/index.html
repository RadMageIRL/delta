delta v1.0_

A local-first diff & compare tool. Delta stores your saved comparisons in this browser's local storage. No account, network connection, or server is required. One optional feature (syntax highlighting) bundles a small third-party library, vendored locally rather than loaded from a CDN - everything else is still hand-written with zero dependencies.

Text Compare

  • Line-level diff with word/character-level highlighting inside changed lines, in Split or Unified view
  • Live mode (auto re-compare as you stop typing) and Preview mode (render Version A/B as HTML or Markdown)
  • Ignore case, ignore whitespace, only-show-changes, and pretty-print-JSON-before-comparing toggles
  • Ignore lines matching (regex) - add multiple patterns as persisted, removable pills; a line matching any of them is shaded/italicized instead of flagged as changed, and it respects the Ignore Case toggle
  • Base / 3-way mode - compare both A and B against a shared original at once, with a full 3-way merge: changes made by only one side (or identically by both) auto-merge, genuine conflicts are flagged for you to resolve (take A, take B, or both, in either order), and the live merged result can be copied, downloaded, or sent back into Version A/B
  • Per-pane find/highlight in Version A, B, and Base, with next/previous jump
  • Font size control and a live line/character count per pane
  • Friendly banners for mismatched line endings, JSON parse fallback, and very large inputs
  • Persistent highlight with click-to-copy on ]/[ hunk navigation
  • In Split view, per-change copy-to-other-side arrows (or alt+→/← on a ]/[-selected change) to move that block from Version A to B or back, with undo support - scrolls to and highlights the result so it's never a mystery where it landed
  • Whitespace toggle - every space (·) and tab (→) made visible everywhere, not just inside a highlighted whitespace-only change
  • Bookmark changes - click a changed row's line number/marker (or press b on a ]/[-selected one) to flag it, then jump between flags with {/}, independent of sequential ]/[ navigation - resets on the next compare, same as fold state
  • Optional syntax highlighting (JS/TS, Python, JSON, CSS, HTML/XML, Bash, SQL, YAML, Go, Rust, Java, C#, C/C++, Markdown) layered underneath the diff coloring, so a changed token still shows both what it is and that it changed - line-by-line, so multi-line comments/strings aren't always recognized correctly

Folder Compare

  • Pick two local folders and diff them by relative path - everything stays in the browser, nothing uploads anywhere
  • Each file is classified added / removed / modified / unchanged using SHA-256 content hashing, not just name/size
  • Filter by status or search by path; click any row to expand it
  • Modified text files open in the same line-diff view as Text Compare; modified images get a side-by-side view plus a pixel-level difference overlay; other binary files report their size change

Save, share & export

  • Save named comparisons as tabs (rename, duplicate, delete), with autosave of the current pair
  • Undo/redo across typing, paste, drag-drop, swap, clear, and load
  • Drag-and-drop a file onto either pane, or use the Paste button
  • Copy Diff, Download .patch, a standalone shareable HTML Report - open it in a new tab or save it as a file - titled after the current saved tab when one's loaded, a Share Link (state encoded in the URL), and JSON Export/Import
  • System, light, dark, and Vegas neon themes on the Theme button, following the system setting by default
